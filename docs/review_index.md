# Review index — where to look first

Navigation aid only, written 2026-10-22. It is **not** an authority: when this file and a record
disagree, the record wins (see `PROJECT_MEMORY.md`, "Authority and evidence order"). The files in
`docs/review/` are append-only. A later `_rN` file supersedes earlier ones in the same stream, but
the earlier ones stay as audit history and are pinned by verifiers, so never delete or edit them.

## Where the files live

- `docs/review/*.md` — reports, QA records, owner decisions (tracked).
- `docs/review/generated/` — manifests, CSV/JSON outputs pinned by verifiers (tracked).
- `docs/review/assets/` — rendered atlases with dataset pixels; **git-ignored**, local only,
  regenerated by each builder's `build`.
- `scripts/build_*.py` — one builder per package; `verify` regenerates and byte-compares.
  `scripts/run_parallel_checks.py verifiers` runs them all.
- `detector/` — separate uv environment (PyTorch/Ultralytics). `m1/` code, `colab/` runners and
  notebooks, `tests/`.
- `results/experiments/` — run outputs and weights (not yet committed).
- `data/`, `tmp/` — local only, git-ignored.
