Subject: Request for provenance, license, and grouping metadata for Vietnam Traffic Signs

Hello,

We are reviewing the public dataset currently presented as **Vietnam Traffic Signs** on
Hugging Face (`thanhhiepvos/vietnam_traffic_sign`) and Kaggle
(`maitam/vietnamese-traffic-signs`). Before using it for model development, we need to
confirm the provenance and governing permissions. Could you please answer the questions
below or point us to an authoritative record?

1. In what capacity are you responding: original photographer/data collector, annotation
   owner, dataset maintainer, authorized representative, or another role?
2. Who owns or is authorized to license the image pixels, annotations, class lists, and
   split files? If different parties govern different components, please identify each one.
3. Which exact license and version governs each component? The public records currently
   conflict: the Hugging Face metadata says CC BY-SA 3.0, while the pinned upload
   description and Kaggle record say CC BY-SA 4.0.
4. Is the Hugging Face revision
   `d869116a5f89e9ba2aa36b1c0582a39c310e3d0c` derived from the Kaggle dataset? If yes,
   which Kaggle version and what transformations were applied?
5. Were any images sourced from third parties? If yes, please provide source URLs,
   permission terms, attribution requirements, and any exclusions.
6. How were the images captured, and are there creator/session/video/route identifiers
   that allow related frames to remain in one evaluation group?
7. Were filters or augmentations from `nguyenmai333/Image-Augmentation` applied? If yes,
   which source images generated which derived images, and with what parameters?
8. Are the existing train/test lists creator-defined? What rule produced them, and were
   near-duplicate or adjacent frames separated across the lists?
9. May the dataset be used, modified, redistributed, and published in research artifacts
   under the stated license, including trained weights and derived annotations?
10. Is there an authoritative citation, dataset card, collection protocol, consent/privacy
    statement, or checksum manifest we should retain?

For an auditable reply, please include your name or organization, role/authority, the date,
the exact dataset version/revision, and links or attachments supporting the answer.

Thank you.
